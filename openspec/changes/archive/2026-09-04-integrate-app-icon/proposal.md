## Why

Knowledge Master previously used an autogenerated placeholder icon and lacked a custom runtime window icon/favicon. A high-resolution custom icon has been provided at `assets/icon.png`. Integrating this icon into both the desktop environment and the runtime application window elevates application branding, visual polish, and user recognition across Linux desktop environments and web browsers.

## What Changes

- Bundle the custom application icon into the package static assets (`src/ebook_editor/static/favicon.png`).
- Configure NiceGUI's `ui.run(...)` in `src/ebook_editor/main.py` with `favicon` pointing to the packaged icon.
- Ensure the installer script `install.sh` copies the updated high-resolution icon to the standard Linux desktop icons directory (`~/.local/share/icons/hicolor/128x128/apps/knowledge-master.png`).
- Version bump to 0.1.3 (patch).

## Capabilities

### New Capabilities
*(None)*

### Modified Capabilities
- `system-packaging`: Updates application icon integration requirements to cover both desktop environment launcher registration and runtime window/browser favicon display.

## Impact

- **User Impact**: The application displays the new custom icon in the OS application launcher, taskbar/dock, native PyWebView window chrome, and browser tabs.
- **Goals**:
  - Full branding consistency between desktop launcher and runtime application.
  - No external build or runtime dependencies introduced.
- **Non-Goals**:
  - Dynamic user-customizable icons.
- **Affected Files**:
  - `assets/icon.png` (already updated)
  - `src/ebook_editor/static/favicon.png` (new packaged static asset)
  - `src/ebook_editor/main.py` (runtime favicon configuration)
  - `install.sh` (system desktop registration)
  - `pyproject.toml` (version bump to 0.1.3)
- **SemVer**: Patch (0.1.3).
